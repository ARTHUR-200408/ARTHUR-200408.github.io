Software-defined networking lab: Mininet and Open vSwitch

Kali Linux in VirtualBox · Mininet 2.3.0, Open vSwitch 4.0.0, OpenFlow · personal project · November 2026

I built a minimal software-defined network (one OpenFlow switch, two hosts and a controller) and watched the controller program the switch. The lab guide was written for Ubuntu, so I adapted every step to Kali.

  • Installed Mininet and Open vSwitch from Kali’s own repositories instead of the guide’s Ubuntu install script.
  • Verified connectivity with ping and pingall: 0% packet loss in both directions.
  • Saw the control and data planes split in the timings: the first ping took 7.79 ms while it went to the controller, and later pings took 0.054 ms on the switch’s own rule.
  • Read the flow table with ovs-ofctl and dpctl: four ICMP rules matching port, MAC, IP and ICMP type with a 60-second idle timeout, plus the table-miss rule that sends unknown traffic to the controller.
  • Fixed problems as they came up: expired flows, a missing service unit, hidden paste characters and command typos.
